## Notes

- Prioritize directories that pass link equity (dofollow) or have high DA
- Complete profiles fully — partial listings rank lower
- Use consistent NAP (Name, Address, Phone) across all listings
- Screenshot each submission for records
- Revisit quarterly to update descriptions and add new features
